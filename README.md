# 🛞 Калькулятор послуг шиномонтажу (Tyre Service Calculator)

Вебдодаток на базі Flask, розроблений спеціально для автоматизації підрахунку вартості послуг та оптимізації роботи шиномонтажу в **с. Білогородка (Київська область)**. 

Проєкт створено як практичну/лабораторну роботу з курсу об'єктно-орієнтованого програмування, а також як реальний бізнес-інструмент для мого батька, що допомагає швидко розраховувати вартість замовлень безпосередньо з мобільного телефона в боксі майстерні.

---

## 🚀 Основний функціонал

* **Адаптивний інтерфейс (UI):** Вебсторінка повністю адаптована під мобільні пристрої завдяки Bootstrap 5. Зручні великі кнопки та випадаючі списки розраховані на швидке тапання пальцем на екрані смартфона.
* **Гнучкий підрахунок:** Автоматичний розрахунок вартості комплексу послуг залежно від типу автомобіля (легковий або кросовер/позашляховик) та діапазону радіуса коліс ($R13$–$R22$).
* **Реальний прайс-лист:** Цінова матриця повністю відповідає чинному робочому прайсу майстерні (з урахуванням групування радіусів: *R13-14*, *R15-16*, *R17-18*, *R19-20*).
* **Контактний блок:** На сторінці виведено точну локацію майстерні та клікабельний номер телефону для швидкого зв'язку з майстром.

---

## 🛠️ Технологічний стек

* **Backend:** Python 3.13, Flask (REST API для обробки запитів на калькуляцію).
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API для динамічного оновлення ціни без перезавантаження сторінки), Bootstrap 5.
* **Управління версіями:** Git, GitHub.

---

## ⚙️ Реалізація принципів ООП (Об'єктно-Орієнтованого Програмування)

Проєкт демонструє практичне застосування фундаментальних концепцій ООП:

1. **Спадкування (Inheritance):** Створено базовий клас `BaseService`, від якого наслідуються специфічні класи послуг: `FixedPriceService` (для фіксованих цін типу заміни вентиля) та `ComplexPriceService` (для цін, що залежать від типу авто та радіуса коліс).
2. **Поліморфізм (Polymorphism):** Перевизначено метод `get_price(car_type, radius)` у підкласах. Обчислення загальної вартості відбувається через єдиний інтерфейс виклику в циклі без прив'язки до конкретного типу об'єкта.
3. **Інкапсуляція (Encapsulation):** Клас `Order` об'єднує в собі всі дані про замовлення (тип авто, радіус, кількість коліс, перелік вибраних послуг) та інкапсулює логіку фінального підрахунку у методі `calculate_total()`.
